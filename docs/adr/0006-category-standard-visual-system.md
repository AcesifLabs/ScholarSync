# 0006 Category-standard visual system

ScholarSync uses a neutral, category-standard visual system instead of a themed world. The quality bar is Linear, Semantic Scholar, Readwise Reader and Zotero 7: identity comes from precision, typography and the reading experience, not ornament.

Inter is the UI face (tabular figures for counts) and Source Serif 4 the reading face for abstracts, notes, discussion and annotation comments, capped at about 66 characters per line. Light and dark themes share one hue; the PDF page stays paper-white in both.

Considered and rejected: a "subject series" world (field-of-study colours, from mid-century paperback series) and a "bound volumes" world (library buckram and gold-stamped spines). Both stay available if the brand is revisited.
